# Fixes: Dashboard Pruner Tool v1.0.0

Fixes made to the migrated app during this review. Two kinds of issue are listed:

- Issues the acceptance suite caught while the app was being migrated.
- Issues from the code review. Each review claim was verified before it was fixed.

Every fix was verified by `pnpm lint`, `pnpm test` and the e2e suite on 2.43 Lao. After the final batch of
fixes, the suite was rerun on 2.40, 2.41 and 2.42 (see UI-TEST-RESULTS.md).
